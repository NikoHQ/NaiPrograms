# NaiPrograms
Scripts propios utilizados en sistema operativo Cachyos, en entorno kde plasma.

contenido:

>nailyrics: comando utilizado como complemento para PyRadio, pero funciona como buscador de letras automático
	y tambien siendo capaz de escanear otros reproductores, tambien cuenta con funcion -s para buscar por titulo y artista
	guarda un historial con las ultimas letras buscadas.
